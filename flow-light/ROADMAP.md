# ROADMAP · flow-light(陪伴型)

> `flow-*` 家族的陪伴轻量版。采用现成好 skill(mattpocock)+ 自建**项目记忆层** + 按需补真实缺口。
> ⚠️ **活文档**:会随实测不停改。checklist 做完就勾 `[x]`。**痛点驱动,不预先建全。**

---

## 一、目标

**一句话**:在高上下文可持续的 host(Codex)上,靠"采用现成好 skill + 项目记忆层",让 AI 陪伴式开发时**全程不跑偏、跨会话不失忆、按项目约束干活**。

具体:
- **G1 采用,不重造**:直接用 mattpocock 的 skill 骨架跑陪伴流。
- **G2 补记忆层(核心差异化)**:一个纯 markdown、手动维护的项目记忆层——记忆/状态/追溯 + roadmap + init。这是 mattpocock 没做全、也是我们真正的增量。
- **G3 只补真缺口**:实测确认咬人的,才补 skill。
- **G4 全程手动可跑**:不依赖任何机器门禁,假设 AI 不折扣执行 AGENTS.md + 指向的 md + skill 提示。

**成功长啥样**:拿一个真实项目,AI 能从 init 建好记忆层 → 陪伴式做任务 → 压缩/换会话后靠记忆层复位不跑偏 → 教训沉淀进记忆层下次生效。全程无脚本。

## 二、范围(明确 in / out)

**✅ In(做)**
- 陪伴型架构;Codex 为主 host(Claude Code 顺带能用即可)
- mattpocock skill 采用 + 项目记忆层 + init + 有限补缺
- 纯 markdown、手动维护

**❌ Out(明确不做,防跑偏)**
- 机器门禁 / git hook / 完成权脚本 / 状态机脚本 —— **v1 就死在这**
- 分解编排型架构 —— 留给 `flow-ultra-max`
- 无人值守 / 多任务并行 —— 陪伴是全程在场
- 发布 / 部署 / 回滚 —— 陪伴开发止于 commit
- 跨全部 host 的通用性保证 —— 先只保 Codex

## 三、步骤(gated,做完打勾)

> **认识修正(为什么没有"玩具试跑"这一步)**:缺口不是靠玩具任务去"发现"的——①玩具任务小到不用任何框架自己就做了,测不出框架的价值;②"裸 mattpocock 新会话会不会失忆"是必然结论(记忆层没建当然失忆),验它没意义。缺口**已经知道**(你的 trellis 实战 + 我们的分析):就是记忆层。所以直接**先设计对 → 搭轻量版 → 在你真实(非玩具)项目上验证它管不管用**。有意义的测试是"**有了记忆层,新会话/长任务能不能正确复位、约束认不认、教训生不生效**",而非验证已知的必然结论。

### P2 · 设计并搭记忆层(轻量 markdown;gate:P1)
按三层落成具体模板:

- [ ] **roadmap 层**:项目级 `ROADMAP.md` 模板(计划 + 进度分开)
- [ ] **init**:新项目建这些文件的说明 + 旧项目扫码反推填充的说明
- [ ] 一个"记忆层怎么维护"的 skill/说明(让 AI 按它读写)
- **完成判据**:结构清晰、你认可,可拿去真项目套。

### P3 · 采用 mattpocock craft + 装配(gate:无,可与 P1/P2 并行)
- [ ] 装 mattpocock 到 Codex(`npx skills@latest add mattpocock/skills` 或 clone → `.agents/skills/`)
- [ ] 定 flow-light 怎么把 mattpocock 的 skill 和我们的记忆层拼在一起用(哪几个 skill、什么顺序、记忆层在哪几步读写)
- **完成判据**:一份"flow-light 怎么用"的说明(mattpocock craft + 记忆层)。

### P4 · 真实项目 dogfood(**唯一有意义的验证**;gate:P2+P3)
- [ ] 在你一个**真实、非玩具**的项目上跑 flow-light(mattpocock skill + 记忆层)
- [ ] 验证(这些才是非必然、真有意义的测试):
  - [ ] 新会话能否**从记忆层正确复位**(有了记忆层还灵不灵,不是"会不会忘")
  - [ ] 项目约束(前后端/架构/风格)有地方放、AI 认不认、遵不遵守
  - [ ] 教训能不能沉淀进记忆层、**下次真生效**
  - [ ] 重构会不会漏功能;没测会不会谎报完成
  - [ ] 长任务里,记忆层帮不帮得上(压缩自然遇到就记,不刻意造)
- **完成判据**:真实规模项目上,记忆层确实让 AI 少跑偏/不失忆。缺什么 → 回 P5 补。

### P5 · 补真实缺口(gate:P4 结果,不疼不补)
- [ ] 按 P4 真实暴露的缺口补 skill(如复盘件、重构反查件)
- **完成判据**:每个补的件都对应 P4 一条真缺口,不无中生有。

5. **先理解再动手**:涉及 skill 机制/框架细节,查证再说。
6. **诚实标注**:抄来的标来源,自组的标自组,没验的标没验。
